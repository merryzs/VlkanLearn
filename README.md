# READ ME

Ceci est le projet pipeline 3D, le but était de faire un beau cube qui tourne sur lui même avec L'API Vulkan.

## se que j'ai appris

Lors de se projet, j'ai appris les bases et la logique derrière Vulkan. C'est comme cela que j'ai comprit comment est créée le système graphique de Vulkan et la relation entre les différents module qui compose vulkan.
J'ai appris le fonctionnement des differents modules comme VertexBuffer ou les Pipelines.
